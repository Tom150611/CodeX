    Hoàn thiện một sản phẩm

    Trang CLB, công cụ học tập hoặc chatbot — sản phẩm có thể mở lên và giới thiệu được.

Web cơ bản

HTML, CSS, JavaScript — dựng được một trang giới thiệu, biểu mẫu hoặc trang đích đơn giản.

Python

Cú pháp, xử lý dữ liệu cơ bản, và xây dựng chatbot hoặc chương trình nhỏ phục vụ học tập.

Giao diện

Bố cục, màu sắc, khoảng trắng. Sử dụng Bootstrap hoặc Tailwind để giao diện gọn gàng, thống nhất.

Git & GitHub

Lưu bài, làm việc nhóm để tránh ghi đè tệp, và đưa mã nguồn lên GitHub.

Backend cơ bản

Node.js và SQL ở mức nền tảng: lưu biểu mẫu, danh sách thành viên, dữ liệu đơn giản.
